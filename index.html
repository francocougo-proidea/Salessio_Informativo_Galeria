3. Como adicionar informativos no Produto?

Clique em Abrir Gestor

Vá em Catálogo -> Produtos.

Selecione o produto que deseja incluir um informativo.

Cole o link que desejar, e depois salve o produto.

OBS: Caso a documentação seja um PDF é necessário enviar o mesmo para a PROIDEA primeiro.
Após confirmação por parte da PROIDEA de que o PDF foi adicionado no Servidor, será enviado um link específico para você usar.

Pronto, agora seu produto possui um informativo que vai redirecionar para o link cadastrado acima.

4. Como adicionar informativos nas opções de uma Característica?

Clique em Abrir Gestor

Vá em Catálogo -> Características.

Selecione a característica onde deseja adicionar um informativo

Clique no sinal de + na opção onde deseja incluir um informativo

Adicione o link no parâmetro Link Documentação, e depois clique em salvar

OBS: Caso a documentação seja um PDF é necessário enviar o mesmo para a PROIDEA primeiro.
Após confirmação por parte da PROIDEA de que o PDF foi adicionado no Servidor, será enviado um link específico para você usar.

Pronto, agora a opção dessa característica tem um informativo cadastrado.

5. Como adicionar uma Galeria em um Produto?

Clique em Abrir Gestor

Vá em Catálogo -> Galleries.

Clique em Cadastrar nova Gallery

1. Digite uma descrição para a Galeria
2. Digite uma descrição para a Imagem que vai adicionar
3. Clique no símbolo ⬆️ para adicionar uma imagem
4. Clique no botão Adiciona para adicionar está imagem na Galeria

Repita os passos 2, 3 e 4  para adicionar quantas imagens quiser.

5. Salve a Galeria

Vá em Catálogo -> Produtos

Selecione o produto onde deseja incluir uma Galeria

No parâmetro Gallery selecione a Galeria que você acabou de criar, e depois salve o produto

Pronto, agora seu produto possui uma galeria.
